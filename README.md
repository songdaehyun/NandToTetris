# Nand to Tetris 학습 기록

Nand to Tetris 프로젝트를 진행하며 작성한 코드와 학습 내용을 정리한 저장소입니다.

논리 게이트부터 컴퓨터 시스템으로 이어지는 구조를 이해하는 것을 목표로,
직접 구현한 코드와 주요 개념을 설명하는 자료를 함께 기록합니다.

### 1. DFF 구현하기

순차 논리 회로의 기본 요소인 DFF를 학습하고,
클록에 따라 값을 저장하고 유지하는 동작을 정리했습니다.

- DFF의 입력과 출력
- 클록과 상태 변화의 관계
- 구현 과정과 동작 이해

📄 [DFF 구현하기 자료 보기](./docs/DFF구현하기.pdf)

### 2. 2의 보수법 원리 설명하기

컴퓨터에서 음수를 표현할 때 사용하는 2의 보수법을 학습하고,
정수와 이진수의 대응관계 원리를 정리했습니다.

- 2의 보수를 사용하는 이유
- 2의 보수로 정수를 표현하는 원리
- 이진수 예제를 통한 이해

📄 [2의 보수법 원리 설명하기 자료 보기](./docs/2의%20보수법.pdf)
